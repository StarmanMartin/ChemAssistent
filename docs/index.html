Chemotion ELN · AI agent

ChemAssistent

Talk to your electronic lab notebook in plain language. Every change runs only after you confirm it.

How it starts

From the top bar to your data in one step

1

Click the Chemotion icon

“Ask Chemotion…” in the top bar menu, or a middle click on the icon.

2

Type your question

A prompt opens in the middle of the screen. Press Enter.

3

The window grows

Chat with the agent on the left, results of each request on the right.

The workspace

Chat on the left, results on the right

Chat

Ask follow-up questions, stop with Esc, use any OpenAI-compatible model.

Result panel

Each request becomes a card: purpose, code, and the result as a table or text.

Always reachable

Minimize it; the top-bar icon brings the conversation back.

You stay in control

Nothing runs without your confirmation

Read

See the purpose and the exact Python code first.

Edit

Change the code; the agent is told what really ran.

Run or Reject

A rejection reason goes back to the agent.

What you can ask

Everything the Chemotion API can do

Collections

“Create a collection for project X and share it with my group.”

Samples

“Add a sample from SMILES N.O with the label Ammonium hydroxide.”

Reactions

“Build a reaction from these samples, heated to 100 °C for one hour.”

Find and list

“Which samples in Main Test have no analyses yet?”

Files and analyses

“Attach this file to research plan 12 and list its datasets.”

More elements

Research plans, wellplates and generic LabIMotion elements.

How it works

One request, five steps

You ask

in the chat

Agent codes

from the API docs

You confirm

in the result card

Code runs

with chemotion_api

Result

table to you, summary to the agent

The agent knows the API from a reference generated out of the documentation of chemotion_api, branch version-3, and can read the package source when it needs more detail.

Safe by design

Powerful, but on a short leash

One tool only

No shell, no file edits, no web access. Chemotion is reached only through confirmed code.

Password stays local

The login happens in the app; the AI model never sees your credentials.

Limited and cancellable

Each snippet runs in its own process, with a time limit and a Cancel button.

Your choice of model

KIT KI-Toolbox by default, or any OpenAI-compatible API; local models for sensitive data.

Get started

Install once, ask from the top bar

Ubuntu

./install.sh

Installs everything, starts the app at login.

Windows

install.ps1

Via MSYS2, with a tray icon.

Then

Open ChemAssistent Settings: Chemotion URL, user, password, AI token and model. Click the icon and ask.
